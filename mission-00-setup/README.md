# Mission 00 — Repository and Workspace Setup

## 1. Task / objective

The objective of this mission was to create a GitHub repository and prepare an organised workspace for completing all the Digital Detective assignments.

## 2. Work completed

- Created a local project folder named `digital-detective-8449`.
- Created all nine mission folders (Mission 00 to Mission 08).
- Created the required README.md files.
- Created the `number_converter.py` file inside Mission 05.
- Created an evidence folder.
- Prepared the root README.md with the project introduction, mission index and tools.

## 3. Commands / tools used

| Command / Tool | Purpose |
|---|---|
| `mkdir -p` | Created project and mission directories. |
| `cd` | Navigated into the project folder. |
| `pwd` | Checked the current working directory. |
| `touch` | Created empty files. |
| `ls -R` | Verified the folder structure recursively. |
| `git --version` | Checked the installed Git version. |
| `python3 --version` | Checked the Python version. |
| `code` | Opened project files in VS Code. |
| Git | Version control tool. |
| GitHub | Online repository hosting platform. |

**Installed versions:**
- Git: 2.56.0
- Python: 3.14.7

## 4. My understanding

A GitHub repository is a place where developers store and manage project files using Git. It helps track changes, maintain project history and collaborate with other developers.

Separate mission folders help organise project files and make them easier to find, understand and maintain.

## 5. Difficulties faced

Initially, the `code .` command did not work in Terminal because the VS Code command-line launcher was not configured in PATH.

## 6. How I resolved them

I opened Visual Studio Code manually and used its Command Palette to install the `code` command in PATH. After restarting Terminal, the command worked successfully.
