# The Digital Detective

## About This Project

The Digital Detective is an independent learning project focused on understanding how computers work. Through practical missions, I will explore computer hardware, software, operating systems, Terminal commands, programming, number systems, GitHub and computer networking.

My goal is to learn these concepts through hands-on experiments, practical activities and documentation rather than simply memorising definitions.

## Project Structure

The repository is organised into separate folders for each mission. Each mission contains its own README documenting the activities, commands, observations and learning outcomes.

Each completed mission will be committed and pushed separately to GitHub.
