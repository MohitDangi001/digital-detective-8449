# The Digital Detective

## About This Project

The Digital Detective is an independent learning project focused on understanding how computers work.

Through practical missions, I explored computer hardware, software, operating systems, Terminal commands, programming, number systems, text encoding, Git, GitHub and computer networking.

My goal was to understand these concepts through hands-on experiments, practical activities and documentation rather than simply memorising definitions.

## How to Run the Number Converter

The project includes a Python program that converts a positive decimal number into binary and hexadecimal.

To run it from Terminal:

1. Open the project folder.
2. Navigate to the converter's mission folder:

   ```bash
   cd mission-05-numbers-data
   ```

3. Run the program:

   ```bash
   python3 number_converter.py
   ```

4. Enter a positive decimal number when prompted.

The program displays its binary and hexadecimal representations.
