## 4. My Understanding

### Understanding IPOS
I learned that a computer works through four main stages: Input, Processing, Output and Storage. For example, when I search for something on the internet, I enter a query using the keyboard, the browser and search engine process my request, and the results appear on the screen.

### Understanding Hardware and Software
Hardware refers to the physical components of a computer that we can touch, such as a keyboard, mouse, RAM and SSD. Software consists of programs and instructions that tell the computer what to do. I also learned that device drivers help the operating system communicate with hardware devices.

### Understanding RAM and SSD
RAM is temporary and volatile memory. Its contents are generally lost when the computer is switched off. SSD is non-volatile storage that retains data even after the computer is switched off.

### Understanding Computer-Based Systems
I learned that everyday devices such as ATMs, smart TVs and washing machines are computer-based systems. They accept inputs, process information and produce outputs to perform specific tasks.
